# Contributing

Use small changes with Node and Flutter tests for affected behavior. Preserve Russian UI, offline data, authentication, owner isolation and provenance. Do not add automatic game-state confirmations or claim mock tests as live provider proof.

Do not submit credentials, personal snapshots, screenshots, databases, signed release keys or production configuration. Use synthetic fixtures. Do not copy commercial guides or bundle Sony artwork. Security issues should be handled privately rather than in a public issue containing secrets.

Generated build/cache files and local SDK configuration are excluded. Keep external API contracts documented and do not introduce paid API calls or silent billing fallbacks.
